This project begins with a deceptively simple objective:

> Build a small Arduino-based system that can measure a real-world phenomenon reliably enough to produce meaningful data.

The project will cover the complete experimental pipeline:

1. Define the question.
2. Select appropriate sensors.
3. Design and build the hardware.
4. Write the acquisition firmware.
5. Calibrate the system.
6. Capture repeatable measurements.
7. Visualize and interpret the data.

## Initial constraints

The finished device should be understandable, reproducible, and reasonably inexpensive.

The build log will document the reasoning behind each decision, including mistakes, failed prototypes, and abandoned approaches.

## Current questions

The first decisions are:

- What physical phenomenon should the system measure?
- What measurement range and precision are required?
- How frequently should samples be captured?
- Where should the captured data be stored?
- How will we validate the readings?
